# Claims Ledger

Every public numerical or causal claim on temidayoafonja.com, with its exact wording,
where it appears, and its verification status.

Prepared August 11, 2026. Maintained alongside the site. Any new public claim should be
added here before it is published.

**Verification key**

- **Operator-verified** — the operator has confirmed the figure and can produce support
- **Needs source** — the figure is published but no source document is on file here
- **Unverifiable as written** — the wording asserts more than the underlying evidence supports
