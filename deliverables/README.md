# Deliverables (not stored in this repository)

This website repository is limited to website source files.

Generated, non-website deliverables — such as the **Capability Position Read
v4.12 / v5.9** workshop package (deck, workbooks, operating docs, audits and
montages) — are delivered directly to the owner as a downloadable attachment and
are intentionally **not** committed here. Binary bundles (`*.zip`) and anything
else placed under `deliverables/` are ignored by `.gitignore`.

If you need the latest workshop package, use the delivered attachment rather than
this repository.
