## 1.0.0 — Monday, August 17, 2026 (initial release)

First customer-ready release of *Keep the Proof*, delivered as a two-file bundle.

### Added
- **Handbook** (`Keep_the_Proof_A_60_Minute_Career_Evidence_System_v1.0.0_FINAL.pdf`), 38 pages: the full teaching, the five-part workflow (Capture / Clarify / Translate / Protect / Retrieve), the Two-Minute Quick Capture and Full Career Evidence Entry tools, the internal-to-portable translation system and Proof Line builder, six completed worked examples (two run end to end), the KEEP / CARE / NEVER confidentiality standard, the 60-minute setup, monthly and quarterly routines, retrieval guidance, and an optional rule-gated AI prompt. Includes two fillable reusable ledger pages.
- **Career Evidence Ledger** (`Keep_the_Proof_Career_Evidence_Ledger_v1.0.0_FINAL.pdf`), 8 pages: the six reusable fillable forms (Quick Capture, Full Entry, Translation worksheet + Proof Line builder, Monthly Proof Sweep, Quarterly Proof Review, Quarterly Evidence Index).
- Brand system: deep navy / warm cream / muted gold / restrained rust; Cormorant Garamond and DM Sans; a three-line "ledger" record mark used in place of any quadrant or circular motif.
- Fillable AcroForm fields throughout (18 in the handbook, 109 in the ledger), each with the print flag set.
- Working hyperlinks to temidayoafonja.com on the cover and every content-page footer.
- Correct document metadata (title, author, subject, keywords) on both files.

### Decisions locked into this release
- Price fixed at $49; product built and finalized for sale now (supersedes the earlier internal memo's $39 and "defer" recommendation).
- Title hierarchy locked: KEEP THE PROOF / How to Track Your Work Accomplishments Before You Need a Resume / A 60-Minute Career Evidence System.
- "resume" used throughout; no accented "résumé."
- The unsafe "personal-device / off-hours" retention loophole from the internal memo was excluded; the product teaches that ownership does not transfer with the device or the hour.
- Prohibited frameworks (density/optionality scoring, the Four Career States, career-state assessment, stay-or-leave/move-plan advice, resume-writing and interview/networking/job-search content) were kept out by design; a single quiet pointer to the Capability Formation Field Kit is included without teaching it.

### QA fixes applied during the build
- Removed stray blank pages that were appearing before each PART divider (collapsed a redundant page break preceding each divider).
- Tightened the 20-row "what the full entry holds" reference table so it no longer spilled two rows onto a near-empty page.
- Fixed two-column fillable field placement: fields nested in tables were landing at incorrect page coordinates because AcroForm ignores the page-layout transform; positions are now mapped through the current transformation matrix and verified against their labels.
- Brought the handbook into the 30–38 page range by converting five hard page breaks between prose sections into soft gaps, with headings bound to their bodies so none strand.
- Replaced author-bio pronouns with the author's name and they/them to avoid guessing pronouns.
- Removed em-dash separators from the Proof Line ingredient list (replaced with sentence form).
