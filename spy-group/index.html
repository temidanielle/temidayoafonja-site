Three directions, one set of facts.

Every one of these is the same website. Identical sections, identical capability copy, identical NAICS codes and acquisition thresholds. What changes is the identity: color, typography, and how the page carries itself in front of a contracting officer.

Pick the one that sounds like the company. The content is already settled, so switching direction costs nothing but a decision.

Option 1 Manifest

The operator's site. Technical, precise, quietly confident.

Neutral charcoal ground with bone paper bands and a single copper accent. Every identifier is set in monospace, so codes read as data rather than prose.

The color is still open. This page ships with a picker in its top bar — Ink, Harbor, Slate, and the original Field green — so you can see the same layout in each and settle it by eye.

This is the direction that looks like it was built by someone who has actually run a warehouse. It signals competence to a technical buyer without raising its voice.

Identical in all three

The substance doesn't change.

Whichever direction he picks, he gets the same argument. These decisions are already made and worth keeping.

What each site says

  • Four competencies, each tagged with its NAICS code — so a buyer can match the page to a solicitation without a phone call.
  • Paths to award, ordered by ceiling — purchase card at $10K, simplified acquisition at $250K, SDVOSB set-aside or sole source at $4.5M, uncapped subcontracting. SDVOSB status presented as an acquisition authority, not a badge.
  • An honest build-out track — which registration rung the company is standing on, rather than implying past performance it doesn't have.
  • Product supply marked "in definition" — the one competency still being decided, stated as such.

How each one is built

  • A one-page site plus a printable capability statement — the single document a contracting officer actually asks a small business for. It prints to one Letter page.
  • Placeholders marked, never faked. UEI, CAGE, name, phone, and city all render as "pending" in the accent color.
  • Fonts embedded in the page. No request to Google, so no visitor's IP address is disclosed to a third party — the same standard as temidayoafonja.com.
  • Plain HTML and CSS. No build step, no framework, nothing to maintain. Works on any host.
Before any of these goes live

Four things only he can answer.

Everything else is finished. These four block publication regardless of which direction wins.

  • The name and the domain. Built as SPY Group on spygroup.com. If it's spelled differently, or if SPY stands for something, the wordmark changes and the letterhead should say so.
  • Registration details. Legal entity name, UEI and CAGE once SAM.gov issues them, SDVOSB certification through SBA's VetCert program, and the final NAICS and PSC code selections.
  • Product lines. Services only, or products too. The fourth competency and the reseller NAICS codes depend on the answer.
  • Contact details and a logo. Name, title, phone, email, business address. All three prototypes use a boxed or circled "S" as a stand-in mark.
